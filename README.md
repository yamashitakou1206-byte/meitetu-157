# SOULBOUND

Undertaleに着想を得た、キャラクター・物語・演出がオリジナルの小規模ブラウザRPGです。

## 起動
`index.html` をブラウザで開いてください。ビルドツールや外部ライブラリは不要です。

## GitHub Pagesで公開
1. GitHubで `undertale-web-game` という **Public** リポジトリを新規作成します。
2. このフォルダ内の `index.html` と `README.md` をリポジトリ直下へアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、Branch を `main`、Folder を `/(root)` にして Save。
5. 数分後、`https://<GitHubユーザー名>.github.io/undertale-web-game/` で公開されます。

GitHub Pagesの公開設定はリポジトリ側で行う必要があります。
